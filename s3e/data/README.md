This folder contains all datasets used in the paper. They are collected from different sources and included in this repo in a standardized format for convenience.

`mt/` is used for experiments measuring the uncertainty of model predictions. German-English (`mt/de-en`) and Estonian-English (`mt/et-en`) are from [WMT18](https://huggingface.co/datasets/wmt/wmt18). Nepali-English (`mt/ne-en`) comes from [Flores200](https://huggingface.co/datasets/Muennighoff/flores200).

`qe/` is used for experiments estimating the quality of predictions from other models. All data comes from [MLQE-PE](https://github.com/sheffieldnlp/mlqe-pe).
